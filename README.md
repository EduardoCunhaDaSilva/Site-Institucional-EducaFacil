# 🎓 Educa Fácil EAD

### Landing page institucional desenvolvida para uma empresa real do segmento educacional.

![Preview do projeto](img/preview2.png)

## 📌 Sobre o projeto

O **Educa Fácil EAD** é um projeto web desenvolvido para uma **empresa real do segmento educacional**, com o objetivo de apresentar a instituição, divulgar seus cursos técnicos e facilitar o acesso de potenciais alunos às informações e ao processo de inscrição.

O projeto foi desenvolvido com foco em uma interface **moderna, responsiva e objetiva**, buscando proporcionar uma boa experiência para usuários em diferentes dispositivos.

Diferente de um projeto desenvolvido apenas para estudo, esta aplicação foi criada para atender a uma **necessidade real de negócio** e utilizada no contexto profissional da empresa.

## 🎨 Design

A interface utiliza uma identidade visual baseada principalmente em **azul, branco e tons escuros**, criando contraste e destacando as principais chamadas para ação.

A página inicial possui uma seção Hero com:

* Chamada principal;
* Descrição dos cursos;
* Botão de inscrição;
* Benefícios;
* Elementos gráficos;
* Imagem relacionada ao público estudantil.

O design foi pensado para transmitir **profissionalismo, confiança e credibilidade**, características importantes para uma empresa do setor educacional.

## 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência consistente em:

* 💻 Computadores;
* 📱 Smartphones;
* 📲 Tablets.

Entre os principais conceitos aplicados estão:
